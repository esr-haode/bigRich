# 大发地产 · 经典大富翁

🎲 一款基于浏览器的经典大富翁游戏，支持 2-8 人对战，包含人机对战和本地存档功能。

## 游戏特性

- 🎮 **多人对战**：支持 2-8 名玩家，可自由设置人类玩家和 AI 玩家
- 🤖 **AI 对手**：智能 AI 会自动购买地产、建造房屋、处理监狱等事件
- 💾 **自动存档**：游戏进度自动保存到本地，下次打开可继续游戏
- 🗺️ **精美界面**：Canvas 绘制的棋盘，支持拖动平移和滚轮缩放
- 🎯 **完整规则**：地产购买、租金支付、房屋建造、机会/命运卡、监狱系统、破产机制

## 游戏规则

### 基本玩法
- 每位玩家初始资金 ¥20,000
- 掷骰子前进，经过或停在起点领取 ¥2,000 工资
- 购买无主地产，向其他玩家支付租金
- 垄断同色地产后可建造房屋（最多 3 栋），大幅提升租金
- 停在"进监狱"格或被卡片送入监狱，需缴纳 ¥500 保释金或掷出双数

### 特殊格子
- 🚩 **起点**：经过或停留领取 ¥2,000
- ❓ **机会** / 🔮 **命运**：抽取卡片，获得奖励或遭遇惩罚
- 💸 **税收**：缴纳所得税（现金 10%，上限 ¥2,000）或奢侈税（¥1,000）
- 🚂 **车站**：拥有越多车站，租金越高（¥300 / 600 / 1,200 / 2,400）
- 💡 **公用事业**（电力公司 / 自来水厂）：租金 = 最近骰点合计 ×4（1 家）或 ×10（2 家）
- ⛓️ **监狱**：探监或入狱
- 🅿️ **免费停车**：领取累积的奖金池

### 棋盘规模
经典 40 格：22 个街区（棕、深蓝各 2 格，其余 6 色各 3 格）+ 4 车站 + 2 公用事业 + 12 功能格。

### 胜利条件
最后一位未破产的玩家获胜！

## 开发说明

### 修改游戏规则

编辑 `js/data.js` 中的常量：
- `START_CASH`：初始资金（默认 20000）
- `GO_SALARY`：起点工资（默认 2000）
- `JAIL_FINE`：保释金（默认 500）
- `HOUSES`：房屋建造规则和租金倍率

### 添加新地产

在 `js/data.js` 的 `BOARD[]` 数组中添加新格子：
```javascript
{ t:'prop', name:'地名', group:'颜色组', price:价格, color:'颜色代码' }
```

### 调整 AI 行为

编辑 `js/game.js` 中的 AI 逻辑：
- `aiBuyDecision()`：购买决策（第 818-826 行）
- `aiStep()`：监狱和掷骰逻辑（第 791-815 行）
